# Codrithm — Where Coders Make History

The official website for Codrithm, a values-driven student technology community rooted in Islamic principles. The site helps junior developers discover the community, its mission, services, projects, events, and leadership team.

## Routes

- `/` — landing page
- `/team` — complete team directory
- `/sitemap.xml` — public XML sitemap

The landing page intentionally features seven team members. The complete shared team dataset is rendered on `/team`.

## Technology

- React 19
- TypeScript
- TanStack Start and TanStack Router
- TanStack Query
- Tailwind CSS 4
- Framer Motion
- Vite
- Nitro with the Vercel preset

The animated hero is implemented with SVG and Framer Motion. The interactive splash cursor uses WebGL directly. The project does not currently use Three.js, React Three Fiber, GSAP, Radix UI, shadcn/ui, React Hook Form, or Zod.

## Local development

Requirements:

- Node.js 20 or later
- npm

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Vite prints the local URL when the server starts.

## Quality checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```

The production build writes a Vercel-compatible bundle to `.vercel/output`.

## Project structure

```text
src/
├── assets/                 Team and project imagery
├── components/             Navigation, footer, cards, and visual effects
├── lib/                    Server error capture and fallback rendering
├── routes/
│   ├── __root.tsx          Application shell and global metadata
│   ├── index.tsx           Landing page
│   ├── team.tsx            Complete team page
│   └── sitemap[.]xml.ts    XML sitemap handler
├── router.tsx              Router and query-client setup
├── server.ts               Nitro server entry
├── start.ts                TanStack Start middleware
└── styles.css              Global theme and component styles
```

`src/routeTree.gen.ts` is generated by TanStack Router and should not be edited manually.

## Content maintenance

- Team profiles are maintained in `src/components/TeamCard.tsx`.
- Landing-page services, milestones, projects, and events are maintained in `src/routes/index.tsx`.
- Site-wide metadata is maintained in `src/routes/__root.tsx`.
- Public social links are maintained in the navigation/footer and contact sections.

## Current limitations

- Contact, newsletter, and RSVP controls do not yet submit to a backend.
- Automated tests have not been added.
- Some team photographs require web optimization.

## Deployment

The Vite configuration targets Vercel through Nitro:

```bash
npm run build
```

Deploy the generated `.vercel/output` bundle through the existing Vercel workflow.
